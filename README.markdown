## Requirements

Requires Jenkins 2.479.3 or newer and Java 17 or newer as supported by your Jenkins
release. The Jenkins baseline defines minimum plugin compatibility, not a
recommended production version: run a currently supported Jenkins release with
the latest security updates.

The CI build uses Java 21 on Windows and Java 25 on Linux.
